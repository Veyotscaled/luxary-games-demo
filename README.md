# Luxary Games — демо для замовника

Ігровий клуб у бордових, фіолетових і золотих кольорах за наданим референсом. Інтерфейс українською, адаптований для телефона і комп’ютера.

## Що працює

- Доміно «Класика» для 2–4 місць: роздача, допустимі ходи, вибір кінця, базар, пропуск, «риба», визначення переможця.
- Доміно «Телефон» із демо-варіантом правил All Fives: сума кінців, очки та бонус за завершення роздачі. Остаточні правила потрібно погодити із замовником.
- Лото: коректні квитки 3×9 із 15 числами, 90 чисел без повторів, автоматичні позначки, швидкість, пауза та виграш повного квитка.
- Лобі, створення кімнат, вибір внеску та кількості гравців. Суперники — боти.
- Демо-профіль із редагуванням імені та аватара, баланс, гаманець умовних фішок.
- Історія зіграних партій, локальна статистика, демонстраційний рейтинг.
- Відкриття/закриття кімнат у демонстраційній адмінпанелі.

## Межі демо

Це статичний прототип, а не готове казино з реальними коштами. Немає сервера, реєстрації з паролем, платежів, спільних кімнат між пристроями чи захищеної адмінпанелі. Демо-профіль, кімнати, баланс і останні 100 партій зберігаються в `localStorage` цього браузера. Статистика ботів у рейтингу є прикладом оформлення.

Внесок списується під час старту гри; виграш дорівнює частці банку столу. Вихід або перезавантаження незавершеної партії не повертає внесок. Фішки не мають грошової вартості. У гаманці можна безкоштовно додати 1 000 демо-фішок.

## Запуск локально

Потрібен Node.js, встановлювати пакети не потрібно:

```sh
npm start
```

Відкрити адресу, яку покаже сервер, зазвичай `http://127.0.0.1:4173/`. Можна також відкрити `dist/index.html` напряму; для стабільного збереження даних рекомендований локальний HTTP-сервер.

## Публікація на GitHub Pages вручну

1. У репозиторії відкрити **Settings → Pages**.
2. У **Build and deployment → Source** обрати **GitHub Actions**.
3. Відкрити **Actions → Publish demo to GitHub Pages → Run workflow**.

Workflow запускається **лише вручну**: завантаження коду в репозиторій не публікує сайт автоматично. Він публікує папку `dist`, тому відносні шляхи працюють і під адресою `username.github.io/repository/`. Доступність GitHub Pages для приватного репозиторію залежить від плану GitHub; за потреби обрати інший статичний хостинг або змінити видимість самостійно.

Налаштування workflow перевірено за [офіційною документацією GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

Для Netlify чи Cloudflare Pages вихідна папка — `dist`, команда збірки не потрібна. Автоматичного розгортання на Sites немає.

## Перевірки

```sh
npm test
npm run check
```

Тести перевіряють цілісність набору доміно, допустимі ходи, блокування, підрахунок All Fives, квитки та виграші лото. Випадковість використовує `Math.random` виключно для демо; вона не підходить для гри на реальні гроші.

## Структура

- `dist/index.html` — інтерфейс та метадані;
- `dist/styles.css` — адаптивний дизайн;
- `dist/engine.js` — ігрові правила;
- `dist/app.js` — інтерфейс, боти, кімнати та збереження;
- `scripts/serve.cjs` — локальний сервер без залежностей;
- `tests/engine.test.cjs` — перевірка ігрової логіки.

Шрифти Manrope і Prata завантажуються з Google Fonts; без мережі використовуються системні шрифти.
